# Результаты этапов 1 и 2, подготовка этапа 3

03.11.2026. Владелец разрешил переходить между этапами автоматически до необходимости
его участия. Системные настройки не менялись, файлы проекта находятся в его каталоге.

## Реализовано

Этап 1: локальный импорт реального ZIP с проверкой SHA-256/UUID/ключей/связей/
порядка и декодированием всех изображений, React/TS strict, последовательная
учёба, пояснения, пропуск/возврат/повтор, IndexedDB и атомарное сохранение попытки
с позицией. Повторный импорт не меняет прогресс, изменённые старые вопросы не
перезаписываются без отдельного разбора. Повторная запись из старой вкладки
обнаруживается по версии сессии, история не затирается.

Этап 2: адаптивные встроенные и отдельные повторы, random 4 фильтра/3 размера,
сохранение/возобновление нескольких приостановленных сессий при одной активной,
поиск/навигация/закладки/статистика, редактируемый черновик ChatGPT только на ПК.
Изменение уверенности — append-only annotation поверх неизменяемой попытки.
Модель детерминированного планировщика описана отдельно.

## Проверено фактически

- typecheck и lint — проходят без ошибок/предупреждений.
- npm test — 23 пройденных теста: реальный архив, ошибочные данные, сохранение,
  идемпотентный импорт, пропуск/повтор, аннотации, восстановление сессии, порядок
  новых вокруг встроенного повторения, random, интервалы и UTC, SQL-права/RLS.
- npm run test:e2e — 4 пройденных сценария в установленном Chromium: реальный
  импорт, ключ на позиции 5, восстановление выбора/ответа после reload, ручной
  переход, пропуск/возврат/повтор, повторный импорт, случайная подборка и позиция,
  закладка/поиск, редактирование черновика без раскрытия ключа, отсутствие кнопки
  ChatGPT в эмуляции Android, показ/увеличение изображения, узкая вёрстка без
  горизонтального переполнения. Скриншоты визуально осмотрены.
- npm run build — production-сборка проходит; ZIP и проверенные приватные
  маркеры вопросника в dist отсутствуют. Vite отклоняет HTTP-запрос к исходному ZIP.
- npm audit — 0 уязвимостей после закрепления исправленной dev-зависимости.
- Ранее на этапе 0: полный Python-аудит — 74 834 проверки, 0 ошибок; 7 тестов OK.

## Пока не готово

Этап 3 только начат: SQL-миграция и 5 тестов прав/RLS подготовлены и выполняются
локально в PGlite. Облачная миграция, Auth, административный импорт в Supabase,
outbox, объединение истории устройств и разрешение облачных конфликтов ещё не
реализованы/не проверены. Для следующего шага нужен личный проект владельца.

Этап 4 не начат: PWA, гарантированный перезапуск без сети, экзамен, резервные
копии. Не очищать локальное хранилище, использовать постоянный адрес браузера.
Реальные Windows/Android и смена ОС пока не проверены; узкая вёрстка и Android
проверены только в эмуляции Chromium на текущем Linux.
