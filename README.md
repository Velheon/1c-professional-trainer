# 1С · Практика

Сайт: https://velheon.github.io/1c-professional-trainer/

Личный тренажёр подготовки к «1С:Профессионал», платформа 8.3.
React + TypeScript strict + Vite + IndexedDB. Интерфейс на русском.

**Локальные этапы 1 и 2 работают. Код этапа 3 реализован, схема применена в Supabase.**
Для первого переноса истории нажмите «Подключить облако» и войдите созданным
Auth-пользователем. Первая синхронизация подтверждена владельцем. Работа на физических
Windows/Android/Linux ещё требует проверки. [Подключение и проверка облака](docs/SUPABASE_SETUP.md).
Код этапа 4 готов: JSON-копии, пробный экзамен и PWA с запуском без сети.
HTTPS-размещение на GitHub Pages проверено. Для завершения приёмки нужна физическая проверка трёх платформ.
[Этап 4](docs/STAGE_4.md) · [Как разместить сайт](docs/DEPLOYMENT.md).

## Запуск

Нужен Node.js (проверено на 26.12.0) и npm. Откройте терминал в папке проекта:

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite, обычно [http://127.0.0.1:5173](http://127.0.0.1:5173).
Нажмите «Выбрать ZIP-архив» и выберите `platform_83_export.zip` из папки проекта.
После проверки появятся 14 разделов и 961 вопрос; выберите первый раздел.

Учебные данные импортируются **через выбор файла в браузере**. Архив не отдаётся
веб-сервером и не включён в сборку. Платного банка в исходниках нет.
Импорт может занять несколько секунд. Исходные тексты, UUID, ключи, порядок и
иллюстрации сохраняются. Повторный импорт того же архива не меняет историю;
изменение/удаление существующего вопроса в новой версии требует отдельной проверки.

Используйте **один адрес и порт**: `localhost` и `127.0.0.1`, а также разные порты,
браузеры и ОС имеют отдельные хранилища. Не очищайте данные сайта и не используйте
приватный режим для постоянной учёбы. До первого подключения история остаётся локальной; сохраняйте JSON через
«Резервная копия истории» на главной. Dev-сервер нужен при разработке. Собранная
PWA после первой загрузки кеширует оболочку и открывается без сети.

## Что доступно

Тёмная тема включена по умолчанию. В шапке можно выбрать светлую или системную;
настройка сохраняется в IndexedDB. Фон и карточки нейтрально-серые, синий используется
для основных действий, ссылок и фокуса. На телефоне «Следующий вопрос» закреплён
у нижнего края с учётом безопасной области экрана. Выбор ответа сразу сохраняет попытку и показывает
пояснение — кнопки «Проверить» нет. Переход к следующему вопросу остаётся ручным.

- Исходный порядок вопросов и ответов, картинки с увеличением, проверка сразу
  при выборе варианта, правильный вариант и пояснение снизу после любого ответа.
- Ручной следующий вопрос, пропуск без попытки, просмотр прошлого ответа,
  явное «Ответить заново». Новая попытка сохраняется отдельной записью.
- Необязательное «наугад» можно менять после ответа; правка хранится событием,
  первоначальная попытка не переписывается. До ответа выбранный вариант и отметка
  также сохраняются при перезапуске.
- Встроенные повторы и отдельная очередь повторения, ступени 1/3/7/14/30/60 дней.
  [Точный алгоритм](docs/REVIEW_ALGORITHM.md).
- Случайная подборка по разделу: решённые / новые / все / проблемные, 10/20/все,
  без повторов, с сохранённым составом/порядком/позицией.
- Поиск по тексту, номеру вопроса или `раздел.вопрос` (например, `2.7`), область
  поиска, фильтры, закладки, навигатор с текстовыми статусами и статистика.
- Редактируемый черновик ChatGPT на ПК; копирование и открытие выполняются
  кнопками, отправляете вы. До проверки правильный вариант в черновик не попадает.
  На Android/iOS сценарий скрыт независимо от ширины окна.
- Сохранённые тренировки разных режимов доступны на главной странице;
  в нормальном сценарии активна одна. Завершение не удаляет историю.

В новой тренировке повторения/random и во встроенном повторении вопрос чистый,
без прежнего выбора, ключа и пояснения. После ответа показывается результат
текущей тренировки. В основном режиме навигатор показывает последний ответ;
для новой попытки нажмите «Ответить заново». Номера вариантов соответствуют
исходному answer_code, порядок строк — answer_order. Ключи не меняются.
Tab / Shift+Tab перебирают все варианты без ответа; Enter или пробел выбирают
вариант. После сохранения фокус переходит на «Следующий вопрос»: ещё один Enter
открывает следующий и ставит фокус на первый вариант. Удержание Enter не листает
вопросы автоматически. Цифры также выбирают вариант, в том числе при фокусе
на кнопке ответа; в текстовых полях сочетания не перехватываются. Вне полей/кнопок
Enter — далее после ответа,
стрелки — переход. Фокус и стандартное управление кнопками сохраняются.

- Пробный экзамен: 14 уникальных вопросов из разных разделов, 30 минут, порог 12.
  Выбор можно менять до завершения; результаты и пояснения открываются после него.
  Экзамен не влияет на статистику изучения и повторения.
- Резервные копии JSON: предварительный просмотр, проверка владельца/банка,
  дедупликация UUID; выбор сохранения текущих сессий/отметок либо восстановления.
- PWA в production: установка, кеш оболочки, перезапуск офлайн, запрос постоянного
  хранения, ручное применение обновления. Банк и PNG остаются в IndexedDB.

## Как проверить вручную

1. Импортируйте архив и откройте первый раздел. В первом вопросе выберите
   **пятую строку (исходный номер 4)**: результат верный, пояснение снизу,
   автоматического перехода нет. У этого варианта внутренний код 4 — это не позиция.
2. Обновите страницу: результат остался. Перейдите далее, пропустите вопрос,
   вернитесь через навигатор. Пропуск и просмотр не добавляют попытки/охват.
3. Нажмите «Ответить заново», выберите неправильный ответ: добавится новая попытка,
   вопрос станет проблемным, охват не уменьшится. Поставьте «наугад», обновите
   страницу и проверьте отметку. Закладка доступна в фильтре «Отмеченные» на главной.
4. Начните случайную тренировку, выбрав «Все вопросы раздела». Перейдите ко второму
   вопросу, обновите страницу: подборка и позиция сохранятся. Вернитесь к прежней
   последовательной сессии через «Сохранённые тренировки».
5. Откройте отдельное повторение после ошибки. Для нового ответа используйте
   «Ответить заново». В последовательном режиме встроенное повторение появится
   после нескольких новых ответов, с пометкой раздела, затем вернётся основной поток.
6. Найдите `2.7`, откройте вопрос и увеличьте изображение. Закройте клавишей Escape.
   На ПК откройте черновик ChatGPT до проверки: он не содержит ключа, текст редактируем.

## Автоматические проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run check:build
npm run test:e2e
```

Unit/integration: 49 тестов (с архивом). При отсутствии личного архива используются
явно синтетические фикстуры «ДЕМО», тест настоящего архива пропускается.
Платные материалы и картинки не копируются в тестовые исходники.

E2E: 14 сценариев, включая настоящий архив, клавиатуру/мобильные размеры,
резервные копии, экзамен, два облачных хранилища и production PWA офлайн.
Для PWA-тестов сначала выполните build; для реального банка нужен исходный ZIP.
Нужен Chromium. Облачные сценарии используют синтетический API без настоящих
учётных данных и обращений к проекту владельца.
В текущей среде используется `/usr/bin/chromium`. Для другой машины можно указать
`PLAYWRIGHT_CHROMIUM_EXECUTABLE` или установить Chromium через Playwright;
для установки браузеров только внутри проекта задайте `PLAYWRIGHT_BROWSERS_PATH=.cache/playwright`.
Снимки, трассы и отчёты тестов содержат приватные материалы и исключены из git.
PGlite запускает настоящие PostgreSQL-права/RLS с синтетическими Auth/Storage-схемами.
SQL также применён в личном проекте; отдельно проверен настоящий анонимный API.
Первый личный облачный вход подтверждён владельцем; физическая смена ОС ещё требует проверки.

Аудит исходника (Python 3.10+ и ImageMagick `magick`):

```sh
python3 scripts/audit_archive.py
python3 -m unittest discover -s tests -v
```

Подробный локальный отчёт: `reports/archive-audit.json`. 74 834 проверки, 0 ошибок;
7 Python-тестов. В исходном архиве: 14 / 961 / 4 143 / 78;
960 текстовых пояснений и 433 ссылки. Проверена точность выгрузки, а не
экспертная актуальность всех официальных ответов. [Отчёт этапа 0](docs/STAGE_0.md).

src/backup — версионированное восстановление, scripts/build-pwa.mjs — кеш оболочки;
supabase/migrations — серверная схема. [Отчёт этапа 3](docs/STAGE_3.md). Вспомогательная зависимость

lint; после замены lint и тесты проходят. `npm audit`: 0 уязвимостей.
