Политики первой миграции проверяются в `tests/access.test.ts`:

```sh
npm test -- tests/access.test.ts
```

Используется локальный PostgreSQL PGlite с синтетическими auth/storage-схемами.
Тесты не подключаются к облаку и не публикуют вопросник. После настройки
личного проекта необходима отдельная проверка через настоящий API Supabase.
